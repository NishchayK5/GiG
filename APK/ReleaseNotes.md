# Release Notes

**Version:** 0.1 - Iteration 1

**Release Date:** February 13, 2025

**Milestone:** Iteration 01

## Overview
This release represents the early phase of development of our application. It includes the fundamental project structure, basic domain models, stub database implementation, real database structure (SQLite Database, though not connected with the business layer) and UI for the first two features. This version establishes the core architecture of the system and demonstrates early features.

## Implemented features

**Feature 01: Account Creation**

The application will provide users the ability to make accounts based on their selected roles and ask for role specific information during account creation and store account data which will be used for authentication.

**Feature 02: Role Based Login and Verification**

The application will allow returning users to login by authenticating users via their saved login credentials and will be shown to either the “Client” home screen or the “Pro” home screen.

**Work in Progress:**

- The landing page of the Client and Pro UI is still under development. 
- Navigation back to the sign-up screen will be supported in a future iteration.


**How to Use this Version:**

- Launch the App
- Select your role, whether you like to register as a Client or a Pro.
- Create an Account by entering valid the required information based on your selected role.
- Login with the registered credentials to log in to the system.
